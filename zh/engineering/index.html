AlephTX

只回放策略当时能看到的数据

分析查询需要易用的数据视图，模拟则要还原数据对策略可见的时点和顺序，还得保留采集缺口。AlephTX 为两种场景保留各自的数据表示。

实时链路中，Go 行情进程通过版本化共享内存向 Rust 策略引擎供数。独立采集链路用 SHA-256 校验原始归档，分别生成供查询的 Parquet 分区，以及按到达顺序生成的模拟回放文件。

Oasis Agent

让回放在失败后安全重试

工作进程可能在领取任务后退出，链重组也可能让输入失效。回放调度既要能恢复任务，也要防止过期结果被写入证据记录。

Oasis Agent 在同一个 SQLite 事务中提交回放任务和覆盖状态。工作进程通过带校验的租约重试，重复完成操作保持幂等，遇到链重组则使受影响的任务失效。每次回放都能追溯到留存的原始数据响应。

2026-11-12机器人数据

从 episode 边界开始检查机器人数据

先抽一小批 episode 做质检。通过元数据定位每段视频、状态和动作的范围，检查时间戳和对齐情况，再决定如何做全量扫描。

需要留意 小样本可能漏掉只在跨文件、跨相机或跨采集批次时出现的问题。初步检查通过后，再扩大覆盖范围。
