AlephTX

Multi-venue order books, causal replay and supervised execution in Rust and Go.

View on GitHub ↗ Quickstart

AlephTX links three workflows. Its Go feeder and Rust strategy engine share a versioned market-data interface. A separate capture pipeline retains the data for replay, so research can evaluate a decision using the information available at the time.

Record
Capture depth, public trades and funding, with independent reference prices and sealed archive segments.
Replay
Compile events in arrival order, model the fills on each leg and attribute fees, funding and post-fill markouts.
Execute with supervision
Track orders and journal recovery. Maker, cancel and taker lanes use separate signing credentials and nonce tracking.

The supervised mode supports Lighter market making and a separately gated Hyperliquid hedge. Paper trading keeps quantitative profit, hedge arbitrage and incentive turnover in separate ledgers.

Oasis Agent

Block-pinned research, deterministic replay and execution with independently enforced limits.

View on GitHub ↗ Quickstart

Oasis Agent retains raw observations and ties them to a chain, block hash and input configuration. It reconciles strategy decisions with balances and receipts. Loss, exposure and transaction-scope checks run independently of the strategy.

Reconstruct evidence
Retain the provider response and replay from pinned state, including the exact pre-transaction state when available.
Run in shadow
Review Uniswap v4 liquidity provision, Base spot paper positions and multihop swap research on retained inputs.
Gate execution
Live canaries require explicit authorization and run within configured bounds. Journals preserve receipts, recovery and STOP state.

The quickstart runs an offline benchmark. The project also documents a bounded Base LP canary and a Base spot shadow ledger. Each new live run requires fresh evidence and approval.
