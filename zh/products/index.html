AlephTX

跨平台订单簿、因果回放与受监督执行，核心由 Rust 和 Go 实现。

GitHub 源码 ↗ 快速开始

AlephTX 将采集、研究与执行连起来。Go 行情进程和 Rust 策略引擎通过版本化的共享内存接口交换数据，独立采集链路保存回放材料，让研究能按决策当时可见的信息检验策略。

采集
连续采集盘口深度、公开成交与资金费率，保留独立参考价，为归档分段做校验。
回放
按数据实际到达顺序重放，建模两腿成交，再核算手续费、资金费与成交后的价格偏移。
受监督执行
追踪订单与恢复日志。挂单、撤单和吃单使用分离的签名密钥与 nonce 跟踪。

受监督模式支持 Lighter 做市，Hyperliquid 对冲单独授权。纸面研究将量化收益、对冲套利与激励周转分别记账。

Oasis Agent

固定区块状态的研究、可复现回放，以及由独立风控限制的执行。

GitHub 源码 ↗ 快速开始

Oasis Agent 保留原始观测，将它与链、区块哈希和输入配置绑定，再用余额和回执核对策略决策。亏损、敞口和交易权限由策略之外的风控层校验。

还原证据
保留数据源的原始响应，按固定状态回放。有条件时精确恢复交易前状态。
影子验证
用留存输入研究 Uniswap v4 流动性、Base 现货纸面仓位与多跳兑换。
审核后执行
实盘小范围验证要求明确授权，按配置限制执行。日志保留回执、恢复记录和停止状态。

快速开始可以离线运行基准案例。仓库也公开了 Base LP 的小范围实盘验证和 Base 现货影子账本。新一轮实盘仍需当期证据与授权。
